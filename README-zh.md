# 懒加载终结者（通用版）

**作用**：让网页上的图片一次性全部加载完，不再需要「往下拉」「刷新一下」。

**适用**：几乎所有用懒加载的网站 —— 漫画站、图集站、论坛图片、长图文、瀑布流……

---

## 一、安装（Edge / Chrome 通用，1 分钟）

1. 打开 `edge://extensions/`（Chrome 是 `chrome://extensions/`）
2. 右上角打开「开发人员模式」
3. 点「加载解压缩的扩展」（Chrome 叫「加载已解压的扩展程序」）
4. 选择本文件夹：`C:\Users\11946\Desktop\懒加载终结者`
5. 完成，图标会出现在工具栏

> 如果 Edge 提示「来自未知来源」，点「允许」即可。

---

## 二、怎么用

装上就自动生效，**不需要任何额外操作**。

打开一个有懒加载图片的网页，顶部会出现一条**紫色进度条**，显示「图片预加载 12/86 (14%)」，
标签页标题也会同步显示进度。全部加载完后进度条自动消失。

点工具栏上的插件图标可以：
- **全局启用 / 关闭** —— 关掉后所有网站都不生效
- **本站启用 / 关闭** —— 只对当前域名生效（某个网站如果显示错乱，就在这里关掉它）
- **立即重新加载本页图片** —— 手动再触发一次

---

## 三、原理

绝大多数网站的懒加载都建立在同一件事上：**IntersectionObserver**（观察元素是否进入视口）。

本插件在页面加载的最早阶段（`document_start`）把这个 Observer 换掉：
观察到的元素**立刻被判定为「已进入视口」**，于是所有图片同时开始下载。

同时并行做了三件兜底事：
- 把 `loading="lazy"` 改成 `loading="eager"`（关闭浏览器原生懒加载）
- 提升 `data-src` / `data-original` / `data-srcset` 等 10 种常见懒加载属性
- 用 MutationObserver 持续接管运行时才插入的图片

因此它**不认识任何网站**，靠的是「打断通用机制」而不是「适配具体网站」。

## 五、已知限制

- **不处理视频**（`<video>` 流式加载）
- **不处理 canvas / WebGL 渲染的内容**（如地图、某些网页游戏）
- **需要登录才能看的内容**不会因为插件而变得可见 —— 权限问题插件解决不了
- 极少数用「非标准私有协议」传输图片的站点（如 WebSocket 推流）不适用
- 对**无限滚动**的站点，会一次性加载更多内容，可能稍微多耗一点流量

发现某个网站显示错乱？在插件弹窗里把「本站启用」关掉即可，不影响其他网站。

---

## 六、隐私

插件不收集、不上传任何数据。全部逻辑在本地浏览器内运行。
唯一的网络请求就是网页本来就要加载的那些图片。
